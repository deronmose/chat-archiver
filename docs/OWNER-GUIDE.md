# Chat Archiver — инструкция владельца

Вы раздаёте **Chat Archiver.exe**. Сами держите у себя **Chat Archiver Admin.exe**: им вы
одобряете людей. В программе для получателей нет ни ключей API, ни токена бота. Ключи
получает только одобренный компьютер, зашифрованными под его личный ключ.

## Один раз: настройка

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и username → получите
   токен. Если токен когда-либо был виден посторонним (в том числе попал в чат), выполните
   `/revoke` и возьмите новый.
2. **Ключи API.** На https://my.telegram.org → API development tools возьмите `api_id` и
   `api_hash` вашего Telegram-приложения.
3. **Admin.** Запустите `Chat Archiver Admin.exe` → вставьте токен, `api_id`, `api_hash` → Save.
   Всё хранится зашифрованным DPAPI в `%LOCALAPPDATA%\ChatArchiverAdmin\`.
4. **Резервная копия ключа владельца.** Settings → Export owner key backup → задайте пароль и
   сохраните файл в надёжное место. **Если ключ потерян** (переустановка Windows без бэкапа),
   все розданные копии перестанут принимать ваши новые одобрения, и программу придётся
   пересобрать и раздать заново.
> **Подготовленные настройки.** Если рядом с `Chat Archiver Admin.exe` лежит `admin-import.bin`
> (зашифрованные настройки для вашей учётки Windows), Admin при запуске сам перенесёт их к себе и удалит файл.
> Настроенный Admin он никогда не перезаписывает. Этот файл не передавайте никому вместе с exe.

## Сборка программы для получателей

Запустите двойным щелчком `build.cmd` в папке проекта (или `.venv\Scripts\python.exe build.py`).
Сборка сама возьмёт из Admin на этом компьютере только публичные данные: имя и id бота и
*публичный* ключ проверки. Токен, ключи API и приватный ключ в сборку не попадают.
Собирать на другом ПК можно так: Admin → Settings → Export build config, а полученный файл положить
в `release\approval.json`.

На выходе в `dist\`:
- `Chat Archiver.exe` — раздаёте его;
- `Chat Archiver Admin.exe` — **оставляете себе, никому не передаёте**;
- `SHA256SUMS.txt` — контрольные суммы.

Пересобирать нужно, только если сменился бот или ключ владельца. Смена токена того же бота
и смена `api_hash` сборки **не требуют**: новые ключи уходят людям в новых кодах активации.

## Как раздавать

- Отправляйте exe **лично** (Telegram, флешка) и сообщайте человеку SHA-256 из `SHA256SUMS.txt`.
  Программа не подписана сертификатом: Windows покажет «Неизвестный издатель». Это нормально,
  но значит, что подмену файла третьим лицом проверяет только хеш.
- Срок доступа 14 дней. В программе он не показывается, поэтому сообщите его сами.

## Каждый день: одобрение

1. Запустите Admin → **Listen**. Пока Listen включён, запросы приходят сразу. Если Admin
   выключен, Telegram хранит запросы до 24 часов.
2. В списке **Pending** видно: имя, @username, ID Telegram, имя компьютера, время.
   **Approve** — человек получает кнопку «Copy activation code». **Deny** — вежливый отказ.
3. **Approved** — кто и до какой даты имеет доступ. **Revoke** отзывает доступ: при следующем
   входе программа увидит отзыв и попросит одобрение заново.

## Что важно понимать

- Одобряйте только тех, кому доверяете. Одобренный человек технически может извлечь ключи API
  из памяти своей запущенной программы. Без собственного сервера это не исключить.
- Если ключи API скомпрометированы, сам `api_hash` на my.telegram.org сменить нельзя. Придётся
  создать новое приложение (новый Telegram-аккаунт) и ввести новые ключи в Admin. Пересобирать
  exe не нужно.
- Нарушение правил Telegram API пользователями (спам, массовый сбор) может привести к отключению
  вашего приложения для всех копий.
