# tg-export / Chat Archiver

> **Chat Archiver** — версия с окном для раздачи другим людям, с одобрением каждого через
> **Chat Archiver Admin**. Ключей API в exe нет. Сборка: `build.cmd` → `dist\`.
> Для получателей: [docs/USER-GUIDE.md](docs/USER-GUIDE.md) · для владельца: [docs/OWNER-GUIDE.md](docs/OWNER-GUIDE.md) ·
> безопасность: [docs/SECURITY.md](docs/SECURITY.md). Ниже — консольная версия `tg-export`.

Выгрузка истории Telegram-групп и каналов, в которых вы состоите, — **только на чтение**.
Работает и там, где в Telegram Desktop кнопка «Экспорт истории» недоступна.
Сделан на замену `unnohwn/telegram-scraper` после его реверс-анализа (см. [docs/REVERSE-REPORT.md](docs/REVERSE-REPORT.md)).

## Установка (один раз)

Нужен Python 3.10+ и [uv](https://docs.astral.sh/uv/) (уже есть на этом компьютере).

```powershell
uv venv --python 3.12 .venv
uv pip install --python .venv\Scripts\python.exe --require-hashes -r requirements.txt
uv pip install --python .venv\Scripts\python.exe --no-deps -e .
```

`--require-hashes` гарантирует, что ставятся ровно те версии библиотек, что проверены (хеши в `requirements.txt`).

## Ключи API

1. Откройте https://my.telegram.org → войдите номером → **API development tools**.
2. Создайте приложение (название любое) и возьмите `api_id` и `api_hash`.

Ключи программа спросит при первом входе и сохранит **зашифрованными** (Windows DPAPI).

## Использование

Все команды — из папки проекта: `.venv\Scripts\tg-export.exe <команда>`.

```powershell
# 1. Войти (код и пароль 2FA вводятся скрыто)
.venv\Scripts\tg-export.exe login          # по номеру телефона
.venv\Scripts\tg-export.exe login --qr     # или по QR-коду с телефона

# 2. Посмотреть свои группы и каналы с их ID (колонка «защ.» = запрет пересылки)
.venv\Scripts\tg-export.exe chats

# 3. Выгрузить чат — по ссылке, @имени или ID
.venv\Scripts\tg-export.exe dump https://t.me/+AbCdEf123
.venv\Scripts\tg-export.exe dump -1001597139842 --media
.venv\Scripts\tg-export.exe dump @channel_name --media --max-media-mb 50

# 4. Когда закончили — завершить сессию
.venv\Scripts\tg-export.exe logout
```

Результат — в `exports\<название>_<id>\`:

| Файл | Что внутри |
|---|---|
| `chat.html` | читаемая история, открывается в браузере, с картинками |
| `messages.csv` | таблица для Excel (кириллица открывается корректно) |
| `messages.json` | все поля для обработки программами |
| `messages.db` | архив SQLite — из него строятся файлы выше |
| `media\` | фото, видео, документы (с флагом `--media`) |

### Полезные флаги `dump`

| Флаг | Действие |
|---|---|
| `--media` | скачать фото/видео/файлы |
| `--max-media-mb N` | пропускать файлы больше N МБ |
| `--retry-failed` | повторить медиа, которые не скачались |
| `--since 2026-01-01` | только сообщения с даты (при первой выгрузке) |
| `--limit N` | не больше N сообщений за запуск |
| `--formats json,csv,html` | какие файлы собрать |
| `--raw` | сохранить полный JSON каждого сообщения от Telegram |
| `--watch 300` | докачивать новые сообщения каждые 300 с |
| `--join` | разрешить вступить в группу по ссылке-приглашению |

**Повторный запуск продолжает с места остановки**: качаются только новые сообщения и недокачанные медиа.
Прервать можно Ctrl+C — ничего не потеряется.

`export <папка>` пересобирает JSON/CSV/HTML из архива без выхода в сеть.

### Ссылки-приглашения

- Если вы уже в группе — `dump https://t.me/+…` просто найдёт её.
- Если нет — программа остановится и скажет об этом. Вступить можно в Telegram вручную или флагом `--join`
  (для групп с одобрением заявок будет отправлена заявка).

## Безопасность

| Что | Как |
|---|---|
| Программа не может ничего изменить в аккаунте | Все запросы к Telegram проходят через фильтр (`tg_export/guard.py`). Отправка, удаление, реакции, «прочитано», выход/вступление в группы заблокированы на уровне кода. Вступление — только с `--join`. |
| Ключи и сессия не лежат открытым текстом | `%LOCALAPPDATA%\tg-export\vault.bin`, зашифровано DPAPI: расшифровать может только ваш пользователь Windows на этом компьютере. |
| Код и пароль 2FA не видны на экране | ввод через `getpass` |
| Никакой сторонней сети | Только серверы Telegram через Telethon. Ни телеметрии, ни автообновлений, ни других адресов — проверено REA. |
| Файлы из чата не выйдут за папку `media` | имена очищаются от путей, `..`, запрещённых символов; путь проверяется перед записью |
| Выгрузка безопасна для открытия | CSV: защита от формул Excel; HTML: всё экранировано, скрипты запрещены (CSP) |
| Зависимости закреплены | точные версии + SHA-256 в `requirements.txt` |

Сессия видна в Telegram → Настройки → Устройства как **tg-export** — её можно завершить и оттуда.

**Помните:** выгрузка содержит переписку и данные других людей. Храните её аккуратно и не публикуйте.
Выгрузка из чатов с запретом пересылки технически возможна для участника, но противоречит воле админа —
решение за вами.

## Проверка

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

17 офлайн-тестов: фильтр запросов, разбор ссылок, очистка имён файлов, архив и возобновление,
безопасность экспорта, шифрование хранилища. Аккаунт для тестов не нужен.
